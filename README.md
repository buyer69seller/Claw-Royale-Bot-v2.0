# 🦞 Claw Royale Bot v2.0

Autonomous AI agent for Claw Royale — auto-join, auto-play, and auto-rejoin games.

## 🚀 Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Setup environment
cp .env.example .env
# Edit .env with your API_KEY

# Run bot
python -m bot.main

# Access dashboard
http://localhost:8080
